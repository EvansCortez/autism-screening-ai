# Libre Baskerville

Unmodified Latin normal-weight 400 and 700 WOFF2 files from
`@fontsource/libre-baskerville` 5.3.0 (OFL-1.1), pinned in the separate
`ui-tests/package-lock.json`. `LICENSE` is copied unmodified from that package.

SHA-256:

- 400: `3eb80fbca70498126925ce16ff5c20b2fa35e67ae7123ddb46302d2778dfbf0e`
- 700: `96fa63376eed93029fa2514a02f5cb80276b016e239426858787de6e794d8619`
- license: `8490e863633e537100d6d18755d994ea30b0b44741876a17809d28becf45ce11`

The application serves these locally; Georgia is the fallback for unavailable glyphs/fonts.
To restore identical vendor files, install the pinned UI dependencies and copy the named
files from `ui-tests/node_modules/@fontsource/libre-baskerville/files/` and its `LICENSE`.
