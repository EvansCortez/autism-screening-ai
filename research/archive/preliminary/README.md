# Archived preliminary exploration

Preserved from the initial exploratory run on 2026-10-11. These artifacts are
historical and excluded from the final experiment runner.

The notebook and `results/` use unoversampled classifiers and median imputation
for flagged ages. The final protocol uses fold-local oversampling and a separate
age/duplicate exclusion cohort. Do not combine the two sets of metrics.

See [the final study](../../STUDY.md) and [final findings](../../FINDINGS.md).
The notebook's output path now points into this archive so rerunning it cannot
recreate an active `research/results/` directory. Original result files have
been moved without changing their contents.
