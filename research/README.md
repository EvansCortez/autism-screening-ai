# Final research study

Start with [STUDY.md](STUDY.md) for the protocol and source evidence, then
[FINDINGS.md](FINDINGS.md) for computed results.

With Python 3.14.5 installed, run from the repository root:

```bash
python3.14 scripts/reproduce.py
```

This creates or uses the project virtual environment, installs `requirements.lock`,
checks dependencies and input hashes, runs tests, and regenerates `evaluation/`,
`circularity/`, `uncertainty/` and `report/` with the seeds, folds and draw counts in
`protocol.json`. It preserves demo models.

Coordination, review and writing aids: [TASKS.md](TASKS.md) (shared task list and handoff
log), [METHODS_GUIDE.md](METHODS_GUIDE.md) (plain-language explanation of the methods),
[PAPER_OUTLINE.md](PAPER_OUTLINE.md) (claims mapped to evidence, with gaps marked),
[RELATED_WORK.md](RELATED_WORK.md) (literature with access levels),
[AI_ASSISTANCE.md](AI_ASSISTANCE.md) (record of AI assistance).

## Final artifacts

- `evaluation/audit.json`: data quality, source equality, legacy split overlap.
- `evaluation/settings.json`: model settings, seeds, hashes, software versions.
- `evaluation/environment.txt`: installed environment capture for that run.
- `evaluation/pooled_metrics.csv` and `fold_metrics.csv`: metrics and confusion counts.
- `evaluation/summary.csv`: repeat means and standard deviations.
- `evaluation/conditional_bootstrap.csv`: conditional group-bootstrap intervals.
- `evaluation/predictions.csv` and `fold_assignment.csv`: predictions and shared splits.
- `evaluation/label_by_score.csv` and `threshold_scan.csv`: label counts by score
  and descriptive cutoff comparisons.
- `evaluation/questionnaire_logistic_coefficients.csv` and
  `questionnaire_coefficient_summary.csv`: training-fold weights in standardized
  and binary-item units.
- `evaluation/tree_depth_metrics.csv`, `tree_depth_fold_metrics.csv`, and
  `tree_depth_summary.csv`: validation performance and training-tree structure
  across specified depths.

- `uncertainty/interval_table.csv`: counts and intervals, each with what it is conditional on.
- `uncertainty/whole_procedure_bootstrap.csv`, `country_cluster_bootstrap.csv`,
  `nested_threshold.csv`, `permutation_null.csv`: checks on how far the binomial standard
  error can be trusted for cross-validated results (see `STUDY.md`).
- `uncertainty/residual_decomposition.csv`, `missing_block.csv`, `subgroup_counts.csv`:
  where the non-questionnaire signal comes from, and descriptive group counts.
- `report/figures/` (SVG, PDF, PNG) and `report/tables/` (CSV, Markdown, LaTeX): publication
  figures and tables generated from the CSV outputs above; they recompute nothing.

Maintained dependency pins are in the root `requirements.lock`. The original UCI
archive is in `sources/`. `REVIEW.md` is an independent historical review;
its status and path references describe the reviewed snapshot.

## Reusable audit
