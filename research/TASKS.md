# Shared task list and handoff log

Working research question: *How much of the apparent ML performance on the UCI Adult
Autism Screening dataset is explained by reconstructing a questionnaire-score threshold,
and what signal remains when questionnaire information is removed?*

This file is the single place where the two AI agents (Claude Code, Codex) and the project
lead coordinate. Read it fully before editing anything in the repository.

## 1. Protocol

**Lock.** Only one agent edits a shared file at a time. Before editing, set the lock in
section 2 (holder, start time, files). When finished, clear it and add a handoff entry
(section 8). If a lock is older than 30 minutes with no file changes, it may be taken over;
say so in the change log.

**Status words.** `DONE-VERIFIED` = independently reproduced by a second agent, with
evidence listed. `DONE-UNVERIFIED` = finished, not yet independently checked. `OPEN`,
`IN-PROGRESS`, `BLOCKED`. `DECISION` = needs the project lead.

**Evidence rule.** A task is not done without a file path and how it was checked. No result,
citation or explanation is recorded unless it can be traced to a file, a fetched source,
or is explicitly marked as a hypothesis.

**Claims rule.** Describe performance as *screening-label agreement*. Do not claim
clinically validated diagnostic accuracy. Do not offer explanations for demographic
associations. Mark every statement as **Confirmed**, **Supported inference**, or
**Hypothesis**.

## 5. Spec for X8: uncertainty reporting

Source: `REVIEW.md` F6, checked against two papers read in full (Bengio and Grandvalet
2004; Varoquaux 2018 preprint) and my own simulation and bootstrap (scratch scripts).

1. Relabel "+/- SD" in `FINDINGS.md` as *split-to-split variability, not a confidence
   interval*. Measured on the real data it is 0.34 and 0.64 of a whole-procedure bootstrap
   standard error (an earlier version of this line said "0.41-0.58 of the binomial standard
   error"; that came from a scratch script with the wrong folds and is withdrawn).
2. Do not describe an exact or Wilson interval on pooled out-of-fold predictions as a
   confidence interval for cross-validated performance. In a simulation with known truth,
   exact intervals covered 88-91% (nominal 95%) even with independent rows and a stable
   model.
3. State what each interval conditions on: single holdout (fitted model, independent test
   rows); fixed documented rule `>= 6` (independent rows); the post-hoc `>= 7` rule (report
   "0 of 704 disagree" as a descriptive fact; any bound is conditional on the sampling
   process and, if given, should be adjusted for the 12 candidate thresholds, 0 through 11).
4. Add, if feasible, a bootstrap of the whole pipeline with fold-safe grouping for the
   imperfect models, and a cluster-aware version for models that use country or ethnicity
   (country-cluster standard error was 3.8 times the row-level one for the non-questionnaire
   logistic model).
5. For near-perfect models report the number and identity of distinct rows misclassified
   (row 37, score 6, labeled NO) instead of a seed-averaged accuracy.
